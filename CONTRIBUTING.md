# Contributing to Aesthetic Bio Maker

Thank you for your interest in contributing to Aesthetic Bio Maker! We welcome contributions from the community to help make this tool even better for everyone.

## Code of Conduct

By participating in this project, you agree to abide by the [Contributor Covenant Code of Conduct](CODE_OF_CONDUCT.md).

## How Can I Contribute?

### Reporting Bugs

If you find a bug, please open an issue on GitHub. Include as much detail as possible, such as:
- A clear description of the bug.
- Steps to reproduce the bug.
- Expected behavior vs. actual behavior.
- Screenshots if applicable.

### Suggesting Enhancements

We love new ideas! If you have a suggestion for an improvement, please open an issue and describe:
- The problem you want to solve.
- Your proposed solution.
- Why this would be useful for other users.

### Pull Requests

1. Fork the repository and create your branch from `main`.
2. If you've added code that should be tested, add tests.
3. Ensure the test suite passes.
4. Make sure your code lints: `npm run lint`.
5. Open a pull request with a clear title and description.

## Development Setup

1. Clone the repository: `git clone https://github.com/vincenzo-afk/Bio-builder.git`
2. Install development dependencies: `npm install`
3. Open `index.html` in your browser to test changes.
4. Run linting before committing: `npm run lint`

## Style Guide

- Use clean, semantic HTML.
- Follow existing CSS naming conventions.
- Ensure JavaScript is documented and follows the project's minimal, no-build philosophy.
